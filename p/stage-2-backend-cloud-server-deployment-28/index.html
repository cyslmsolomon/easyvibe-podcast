一、这一集在解决什么问题

前面几集我们把「把东西放上网」变成了几次点击：推代码、连仓库、等构建。但只要你继续往前走，就会撞上两个真实世界的门槛。

第一个门槛是选择过载。托管平台远不止你听过的那两三家，它们各有脾气：有的插件多，有的专治常驻服务，有的对国内网络友好，有的免费但会睡觉，有的真能二十四小时不休眠。选错平台，轻则多花冤枉钱，重则上线第一天就被冷启动拖垮体验。

第二个门槛是自己掌控服务器。一旦你买了一台云服务器，安全组、防火墙、域名解析、初始化、文件存放位置，每一环都有新手必踩的坑。其中「程序跑起来了但外面访问不到」这一条，几乎是所有人的第一课。

这一集的目标，就是给你一张可执行的地图：先按项目形态挑平台，再按场景挑云产品，最后把最容易出错的三件事（端口、密钥、文件存放）一次讲透。

如果你只有五分钟，可以直接跳到文末的「一页纸速览」和「审查清单」；如果你想把这一块真正学扎实，建议按段落顺序往下读，并在读完之后，用自己手头的一个小项目，把清单里的每一条都真实走一遍。部署这件事，看会的和做会的之间，差着一次真机操作。

三、能力地图

完成本集学习与实践后，你应该能够：

  1. 按形态选型：纯静态站、常驻后端、需要算力的一次性任务，分别知道该落哪个平台。
  2. 读懂免费额度：能分辨「永久免费」「试用额度」「按量计费」三种措辞背后的真实成本。
  3. 识别休眠陷阱：看到「无访问即休眠」就知道它不适合面向用户的生产服务。
  4. 配置网络入口：独立开放 22 / 80 / 443 端口，理解安全组与系统防火墙是两层。
  5. 完成域名解析：为根域名、www、接口子域名各配一条 A 记录。
  6. 归并云产品：把云厂商的商品名翻译成四类通用能力，并说出各自的适用边界。
  7. 安全存放文件：把用户上传内容放进对象存储，把访问密钥放进服务端环境变量。
  8. 向人工智能提需求：用一段结构化描述，让助手生成完整的服务器初始化命令。

四、逐段要点

开场 · 从托管平台到自己买服务器

本集分三段推进：先认识更多平台，再处理自己买服务器后的网络与域名问题，最后归并云厂商产品并重点讲对象存储。核心产出是一张「项目形态 → 落点」的映射表。

二 · 老牌静态托管

免费额度为每月 100 GB 带宽 + 300 分钟构建时间。差异化优势在插件市场：表单处理、图片优化、A/B 测试都可插件化；分支预览让每次改动都有独立预览地址。与 Vercel 的差异是中立性——它不绑定特定框架，而 Vercel 对 Next 有深度优化。纯静态站两者皆可。

三 · 后端常驻服务体验最佳的一家

适合常驻后端、Node / Python / Go 接口、长期挂机的机器人、依赖数据库的全栈项目。流程为：GitHub 登录 → 新建项目 → 从仓库部署 → 自动检测与构建 → 一键添加数据库 → 绑定域名。定价需特别注意：新用户五美元为试用额度而非永久免费；空闲五分钟休眠仅发生在免费阶段；三条限制分别是无永久免费层、成本按量不可完全预测、无原生图形处理器。

四 · 三张性格不同的牌

  • 国内友好型：中文界面、国内访问好、支持几乎所有常见语言与一键模板，数据库内置，付费方案三十元/月起。
  • 免费但休眠型：750 小时/月、静态站免费；但十五分钟无访问即休眠，冷启动十到三十秒，免费数据库九十天后删除。适合测试与作业。
  • 真正不休眠型：三台 256 MB 微型虚拟机、不限运行时长、160 GB 出站、3 GB 持久卷、三十多个数据中心、支持图形处理器。代价是需要信用卡验证、命令行工具与配置文件，学习曲线更陡。

五 · 三个小众但好用的选择

静态站托管（推送即上线，适合博客文档）、人工智能演示托管（免费处理器小实例，社区活跃）、无服务器算力（每月三十美元额度，Python 函数即服务）。三者的共性是单点极致，选型问句应是「哪个最贴合我当前场景」，而不是「哪个最强大」。

六 · 安全组与防火墙

端口表：22 远程登录（建议限制来源地址）、80 普通网页、443 加密网页、3000-3999 开发调试（用完即关）、8080 备用。

关键认知：安全组是云厂商层，ufw 是服务器内部层，两层都放行才能访问。故障话术：把报错原文交给人工智能助手，让其从网络、安全组、防火墙、密钥权限四个角度排查。

初始化提示词模板：说明系统版本（乌班图 22.04）、项目类型、需要的动作（更新系统、创建非管理员用户、配置密钥登录、安装 Docker 与网页服务器、配置基础防火墙）。

七 · 买域名与解析

价格参考：点 com 约 55-75 元/年，点 cn 约 29 元/年。同厂商购买域名与服务器配置更省心，但价格未必最优。解析为三条 A 记录：@ 指向公网地址、www 指向同一地址、api 指向接口子域名。命名三原则：短、好念、不易拼错。

八 · 云产品的四类归并

类别典型商品名何时使用
云服务器ECS / CVM / Lighthouse / HECS / EC2需要自掌控环境、跑常驻进程
函数计算FC / SCF / Lambda偶发触发、流量波动大
容器服务ACK / TKE / EKS多服务微服务、自动扩缩容、有运维能力
对象存储OSS / COS / S3图片视频等大文件、静态站点托管、备份

补充：云硬盘是挂载式块存储，系统盘通常 40-60 GB，不足可加挂数据盘，其生命周期独立于服务器。

九 · 对象存储与收尾

铁律：用户上传文件不要放服务器本地磁盘。费用参考：标准存储约每 GB 每月 0.12 元（国内两家），亚马逊云约每 GB 每月 0.023 美元。创建流程为建桶（名称全局唯一、地域就近、标准存储）→ 设读写权限（初期公共读）→ 上传 → 取链接用于前端。两个提醒：绑定自定义域名 + 内容分发网络可提速省流量；访问密钥等同密码，禁止硬编码进前端或提交到仓库，泄露后立即禁用并更换。

五、审查清单

上线前请逐条打勾：

  • 已按项目形态选定平台，并确认免费额度是「永久」还是「试用」
  • 若平台存在休眠机制，已确认该项目不面向真实用户，或已付费关闭休眠
  • 免费数据库已知晓有效期，并配置了定期备份
  • 安全组已放行 22 / 80 / 443，调试端口 3000-3999 已关闭
  • 服务器内部防火墙与安全组两层都已放行
  • 域名已完成三条 A 记录解析，并验证可访问
  • 服务器初始化由非管理员用户 + 密钥登录完成，未长期使用管理员账号
  • 用户上传文件写入对象存储，未落在本地磁盘
  • 访问密钥存放于服务端环境变量，未出现在前端代码或 Git 历史中
  • 对象存储已绑定自定义域名并接入内容分发网络
  • 已确认所选云产品类别（服务器 / 函数 / 容器 / 存储）与业务形态匹配

六、实践提示

提示一 · 用「是否常驻」做第一刀切分

选型时先问一个问题：这个进程需要一直跑着吗。需要常驻的（接口服务、机器人、定时任务）走 Railway、Fly 这类容器或常驻型平台；不需要常驻的（纯静态站、偶发函数）走静态托管或函数计算。这一刀能砍掉八成的纠结。

提示二 · 把「免费」翻译成三个具体问题

看到免费额度，立刻追问：到期后怎样、空闲后怎样、数据库保留多久。这三个问题的答案，决定了它是可以长期托付的平台，还是只够做演示的沙盒。 Render 的九十天数据库删除规则，就是最典型的例子。

提示三 · 访问不到的时候，先看安全组再看代码

「程序起来了但访问不了」的排查顺序应该是：安全组端口 → 服务器内部防火墙 → 服务监听地址 → 应用日志。绝大多数问题停在第一层。养成买完服务器先配安全组的习惯，比事后排查省十倍时间。

提示四 · 让人工智能写初始化命令，但要给它完整上下文

初始化命令是可以放心交给助手生成的，前提是你在需求里写清四件事：操作系统与版本、要部署的项目类型、需要完成的动作清单、是否需要创建非管理员用户。上下文越完整，生成的命令越接近可直接执行。

提示五 · 密钥的位置决定你的安全下限

访问密钥泄露的常见路径只有三条：写进前端代码、提交进仓库、贴进聊天记录。只要做到「只存在于服务端环境变量」这一条，就能挡住绝大多数事故。一旦怀疑泄露，不要犹豫，立即禁用并更换，成本远低于事后补救。

九、常见误区与纠正

误区一：把「试用额度」当成「永久免费」。

很多平台注册即送一笔金额，看起来和免费无异，但消耗完之后服务会直接停止。判读方法是看官方措辞里有没有「永久」「always free」这类限定，没有就一律按试用处理，并在额度接近耗尽前做好迁移准备。

误区二：认为程序能跑就等于能访问。

本地能启动、日志无报错，只说明应用层面健康。外部能否访问，取决于安全组、系统防火墙、监听地址三者是否都对。把这三项写进你的上线 checklist，能避免绝大多数「明明没问题」的困惑。

误区三：为了省事把调试端口长期开放。

三千到三千九百九十九这一段是开发调试用的，部署完成就应当关闭。长期开放等于把内部服务暴露在公网扫描之下，是低成本却高收益的安全动作。

误区四：用管理员账号做所有操作。

初始化时创建非管理员用户并配置密钥登录，是服务器安全的基本功。日常全部使用管理员身份操作，一次误操作就足以让系统无法启动。

误区五：把用户上传的文件留在服务器磁盘。

服务器会重装、迁移、扩容，本地文件随时可能丢失，而且多实例部署时文件还不共享。对象存储从第一天就要接上，后期迁移的代价远高于一开始就接对。

误区六：为了便宜把生产项目放在会休眠的免费层。

十五分钟无访问就休眠，意味着第一位访客要等十到三十秒，这是最伤转化率的体验。演示可以，面向真实用户请至少升级到不休眠的档位。

十、一页纸速览

  1. 形态决定平台：纯静态走静态托管，常驻后端走常驻型平台，偶发任务走函数计算。
  2. 看到免费先问三句：到期怎样、空闲怎样、数据库留多久。
  3. 买完服务器第一件事是配安全组，不是装环境。
  4. 域名解析三条 A 记录：根域名、www、接口子域名。
  5. 云产品只有四类：服务器、函数、容器、对象存储，外加一块云硬盘。
  6. 用户文件进对象存储，密钥进服务端环境变量。
  7. 上线前过一遍审查清单，比上线后救火便宜得多。
  8. 初始化命令可以交给人工智能助手生成，但系统版本、项目类型、动作清单这三件事必须写清楚。
