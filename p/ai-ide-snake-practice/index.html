一、这一集在解决什么问题

上一集我们回答了「AI IDE 是什么、和普通 IDE 差在哪、七款工具怎么选」，但全部停留在认知层。这一集是第三章的实战篇，目标只有一个：让一个零基础的人，在自己电脑上，从零做出一个能玩的贪吃蛇游戏。

原文把这次实战拆成一条清晰的主线：新建一个空文件夹 → 用 AI IDE 打开 → 在侧边栏聊天，让它用 React 从零生成贪吃蛇。围绕这条主线，原文补了三块必要的铺垫：

  1. 工具铺垫——Trae 是什么、装哪个版本、要不要花钱、界面长什么样；
  2. 模型铺垫——免费模型怎么接、付费套餐（Coding Plan）是什么、怎么买怎么接；
  3. 交互铺垫——AI 执行中会暂停等你、报错了怎么处理、做完了怎么确认和回退。

音频稿按「认工具 → 定版本 → 接模型 → 认界面 → 建目录 → 开口做 → 应对暂停 → 收尾确认」的顺序重排了这些内容。一句话概括这一集：本地 AI 编程不是看演示，是真的能在自己电脑上，说一句话，做出一个东西。

三、版本选择：为什么零基础先装中国版

原文对 Trae 两个版本的区别讲得很直白：国际版下载地址是 trae.ai，需要能够访问海外网络，好处是能用 GPT-5 等最新的海外模型；中国版下载地址是 trae.cn，主要支持国内最新的大模型，例如 GLM、Qwen、Kimi 等。

原文给出的建议非常明确：零基础入门强烈推荐中国版。理由有三条，且全部可验证：基础功能免费、无需海外网络、目前整体使用体验更好。原文也如实记了中国版的缺点——用户较多，高峰期可能偶尔需要排队等待。

国际版的价格，原文记录为大约每月三美元。这个价格本身不贵，但它隐含一个前置条件（海外网络），对零基础者恰恰是最难跨过的一道。音频稿把选择逻辑压成一句话：先装中国版把完整流程走完，等真的有海外模型需求再换，不要在第一晚就挑战网络问题。

还有一类读者原文专门照顾到了：如果你之前已经在 z.ai 或其他网页端 AI 编程平台上开发过项目，可以直接把代码下载到本地，解压后用 Trae 打开该文件夹，在侧边栏继续与 AI 对话、迭代优化。原文点明了这样做的好处——既保留之前的成果，又能享受本地 IDE 更强大的 AI 辅助能力。原文给出的三步（下载、解压打开、侧边栏继续对话）同样适用于其他网页端平台迁来的项目。

四、模型接入：从免费到付费的三级台阶

这一节是原文信息密度最高的部分，音频稿把它整理成「三级台阶」结构，建议听众按台阶顺序走，不要跳级。

第一级，免费试用（推荐所有初学者从这里开始）。 原文默认推荐 OpenRouter 方案接入自定义模型——它提供了统一的 API 接口，可以方便地接入多种大语言模型。重点信息有两个：其一，截至教程编写时间（原文明确标注为二零二六年二月十二日），仍可免费试用阶跃星辰 StepFun 的模型，具体型号为 stepfun/step-3.5-flash:free，可在 Trae 中直接接入；其二，还有一个 openrouter/free 选项，这是默认使用免费接口的模型选项，把模型 ID 直接写进 Trae 的自定义模型（Custom Model）即可，无需付费。原文的结论是：这些免费选项非常适合初学者体验，在正式投入生产环境前，先通过这些免费方案熟悉 AI IDE 的工作流程。

第二级，按量充值（以 DeepSeek 为例）。 原文给了完整的五步路径：访问 DeepSeek 平台并注册登录；在充值页面购买十元的用量包；充值成功后，在 API Keys 页面创建并复制 API Key；在 Trae 中点击 Add Model，找到 DeepSeek，选择对应模型，输入 API Key 即可使用。这里有一个原文特意强调的操作细节：添加自定义模型时，模型选择的选项一定要滑动到最底部，最下面有一个「自定义模型」入口，点击后才能输入模型 ID（如 stepfun/step-3.5-flash:free），同时可点击「获取 Key」前往官网获得对应的 API Key。另外，如果充值，原文建议先充十元感受一下能用多久——DeepSeek 等模型性价比较高，十元足够完成大量试错。

第三级，订阅套餐（Coding Plan）。 原文解释：Coding Plan 是各大云服务厂商推出的订阅计划，购买后可以在一定时期内无限制或高频次地使用该厂商的大模型 API。相比于按 Token 计费，它更像「包月套餐」——付一笔固定费用，就能放心大胆地一直用，不用担心每次调用都计费。原文推荐的国内选项有两个：智谱 AI（BigModel Plan，官网 bigmodel.cn/glm-coding）和火山引擎（字节云 AI Plan）。接入步骤同样只有五步：访问官网、注册登录、找到「定价」或「Coding Plan」页面、选择套餐完成支付、获得 API Key 或 Plan ID。

此外，如果你已经有国内大模型的 API（如 DeepSeek、通义千问、Kimi 等），可以通过 Trae 的第三方模型配置功能直接接入，灵活控制成本。这是介于第二级和第三级之间的灵活选项。

五、界面与模式：三分钟建立空间感

原文对 Trae 界面的介绍可以压缩为一张认知地图。整体是经典三栏：左侧资源管理器、中间编辑区、右侧扩展面板，与日常使用的 VS Code 高度相似。核心部件有三个：

  1. 右侧边栏（Copilot 交互窗口 / Agent 窗口）——与 AI 对话的主入口。如果暂时看不到，点击 Trae 右上角的侧边栏图标即可打开。
  2. Builder 选项（Agent 模式）——原文的原话是「相当于 z.ai 的本地版」，可以帮你操作本机环境，安装运行环境、打开网页等。这是今天实战的引擎。
  3. 模型选择区——位于界面下方，点击即可修改当前使用的大模型。中国版可选 Kimi k2、GLM 等国内模型；国际版可选 ChatGPT、Claude 等海外模型。

Builder 展开后有两种模式：Chat 模式主要用于和当前文件夹里的代码对话，或当作普通聊天模型使用（在 File 菜单打开文件夹后，Builder 创建或修改的文件都只会发生在该文件夹内部，这是一个安全边界）；Builder with MCP 模式为 Agent 提供了更多可用工具（例如把语言模型和其他软件联通起来、查询天气等），原文对 MCP 的通俗解释是「能让语言模型更方便地调用各种外部工具」。

关于模型选择，原文给了两条重要提醒。第一，不推荐使用 Auto 模式（自动选择模型）；国际版推荐 Gemini 或 GPT 模型，国内版推荐尝试 Kimi k2、Minimax、GLM 等国内模型。第二，不同模型有不同的使用场景，没有教条式的一定谁比谁好——遇到困难无法解决时，换一个模型，通过多次测试得到属于自己的最佳实验结果。原文还如实指出，国内大模型发展非常快，Kimi、Qwen、GLM 在很多任务上的实际体验已经接近 Claude 3.5 或 3.7，对日常开发来说完全够用，因此不强制要求使用国际版或国内版。

六、实战两步：空文件夹与那段提示词

第一步，新建空文件夹并用 AI IDE 打开。 在本地新建一个名为 snake-game-react 的空文件夹；打开 AI IDE，在启动界面选择 Open Folder 将该文件夹作为项目根目录导入，或直接将文件夹拖入 IDE 窗口。确认信号是：左侧资源管理器中不会出现任何代码文件——表示正从一个完全空白的项目状态开始。

第二步，在侧边栏聊天，让 AI 用 React 设计贪吃蛇。 打开侧边栏（一般为按 Ctrl+L 或点击右侧聊天图标），输入原文给出的提示词：

请你用 React 架构实现贪吃蛇游戏，包含键盘控制、吃到食物变长加分、撞墙或撞到自己时显示「游戏结束」并支持重新开始。实现后帮我启动这个项目。如果遇到没安装的程序环境就自动安装没安装的环境。

这段话值得逐句拆解，它是「结构化提示词」的活教材：架构（React）、功能清单（键盘控制、变长加分、撞墙或撞到自己显示游戏结束、支持重新开始）、交付标准（实现后帮我启动项目）、兜底条款（缺环境自动安装）。音频稿建议原样照抄，正是因为它同时满足了上下文与边界两个要素。

在这个过程中，原文强调了一个观念转变：AI 不只是聊天模型，它能够帮助你操作本机环境——创建文件、安装依赖、执行启动命令等。你可以直接用自然语言描述想要达成的目标，由 AI 来决定具体执行哪些命令、如何组织代码。如果执行过程中遇到问题，AI 会在对话里展示报错和处理方案，你可以继续通过对话让它调整，而不必自己记住所有命令细节。

七、暂停交互与异常处理：新手最慌的十分钟

原文用大量篇幅讲「AI 停下来等你」的情况，因为它恰恰是新手第一次实战最容易懵掉的环节。核心认知只有一句：AI Agent 会在执行过程中暂停，是因为它需要等待你输入一些信息进行交互。

原文列举的常见暂停形态包括：需要输入创建的名字；需要回车确认指令执行；需要点击指令（如界面上的 Run 按钮）进行执行；或者只需要输入 y 即可确认。一般情况直接回车即可。如果你不确定当前步骤需要做什么，原文给的万能招式是——截图当前界面询问大模型应该如何操作。

还有一种特殊暂停：如果此时启动了一个「服务」（贪吃蛇本身属于一种服务），服务需要持续启动，界面会陷入暂停状态，此时只需要点击 Skip 按钮，然后访问对应的本地网址即可访问游戏。

异常处理路径原文同样明确：如果遇到不符预期的现象（例如贪吃蛇撞墙后不会结束游戏、点击开始后不会移动），把现象描述给侧边栏 Agent 即可；遇到报错问题，记得截图或者复制错误到侧边栏 Agent；如果多次仍然不能解决问题，请尝试更换模型操作。此外，过程中遇到术语和看不懂的内容，可以查阅课程附录中的「计算机术语解释」部分，或者直接向 AI 咨询。

八、约束说明

这一集是纯操作手册，但有以下边界，听之前要心里有数：

  1. 教程中的产品信息有时效。 原文明确标注了多个时间锚点：StepFun 免费模型的可用性截至二零二六年二月十二日；国际版约每月三美元；国内模型体验接近 Claude 3.5 或 3.7。免费模型是否还免费、价格是否变化，请以各平台当前信息为准。
  2. 免费方案用于学习，不用于生产。 原文说免费选项「非常适合初学者体验，在正式投入生产环境前熟悉工作流程」——注意限定词是「体验」和「熟悉流程」。真实项目请使用付费 API 或 Coding Plan。
  3. 网络条件是硬约束。 国际版需要海外网络才能使用，这不是工具缺陷而是客观限制。零基础者不必在第一晚挑战它。
  4. 高峰期排队是中国版的已知代价。 原文如实记录「用户较多可能偶尔需要排队等待」。遇到排队，可以考虑接入第三方模型或购买云厂商的 Coding Plan 获得更稳定的服务。
  5. 「不推荐 Auto 模式」是建议而非禁令。 原文的核心态度是「没有教条式的一定谁比谁好」，Auto 模式可以用，但原文更推荐你主动选择并记录不同模型的表现，形成自己的测试结论。
  6. 口播稿对原文做了口语化压缩。 模型 ID、官网地址、部分界面细节（如 Add Model 各选项位置）以原文和实际软件界面为准；软件版本更新后界面可能变化，请以你看到的界面为准。
  7. 代码所有权与责任在人。 AI 生成代码、安装依赖、执行命令，都是在你的本机环境中发生的。确认变更（对勾）之前，请养成展开 review 的习惯；不满意就 Revert 回退。

九、审查清单

实战当晚卡住时，按这份清单逐项自查。任何一项答不上来，就回到音频对应段重听：

  • 我说得出来 Trae 是什么、谁开发的、基于什么构建，以及为什么这对 VS Code 老用户友好。
  • 我知道国际版和中国版的区别（网络、模型），以及零基础为什么先装中国版。
  • 如果我在网页端平台有旧项目，我知道怎么把它搬到本地继续开发。
  • 我记住了免费模型接入路径：OpenRouter 方案、StepFun 免费模型、openrouter/free 选项。
  • 我知道 DeepSeek 充值的完整五步，以及「自定义模型要滑到最底部」这个坑。
  • 我能解释 Coding Plan 是什么、和按量计费的区别，以及国内两个推荐入口。
  • 我认得 Trae 的三栏布局，知道侧边栏在哪里打开、Builder 是什么、Chat 和 Builder with MCP 的区别。
  • 我知道为什么不推荐 Auto 模式，以及卡住时的标准动作是换模型。
  • 我建好了 snake-game-react 空文件夹，并通过「资源管理器空白」确认了打开成功。
  • 我能复述那段 React 贪吃蛇提示词的四个组成部分。
  • 我知道 AI 执行中暂停是正常的，并记得三种应对：直接确认、点 Skip、截图问 AI。
  • 我知道做完之后的两个收尾动作：确认变更（对勾 / Cancel / 展开 review）和 Revert 回退。

十、实践提示

提示1 · 把那段提示词一字不差地先打在备忘录里

实战当晚，不要现场组织语言。现在就把原文那段 React 贪吃蛇提示词存进手机备忘录或微信文件传输助手，做的时候直接复制粘贴。第一次的成功率，很大程度上取决于你有没有在慌乱中把需求说完整。这段提示词也是你以后的模板库第一号藏品。

提示2 · 用「免费模型 + 十元 DeepSeek」组合跑完第一晚

按原文路径，第一晚用 StepFun 免费模型或 openrouter/free 选项把全流程跑通；如果免费模型排队或效果不稳，再充十元 DeepSeek 作为备用。十元钱足够你完成几十轮对话迭代。这个组合的成本几乎为零，但能让你完整经历「接模型 → 提需求 → 遇暂停 → 排故障 → 收尾」的全套动作。

提示3 · 故意制造一次故障，练熟排障三件套

游戏跑通之后，别急着庆祝。故意提一个会出错的需求，比如「把蛇的速度改成每秒一百格」，然后完整走一遍原文的排障路径：现象描述给 Agent，报错截图或复制给它，一次不行就换一个模型。提前在安全的环境里练熟这三个动作，真实遇到问题时你就不会慌。

提示4 · 给每次「暂停」建一个决策卡片

实战时在旁边放一张纸，左边写你遇到的暂停类型（要起名、要回车、有 Run 按钮、输 y、服务挂起），右边写你的动作（照做 / 点 Skip / 截图问 AI）。填完这张卡，你会发现自己再也不会被「AI 停下来」吓到——暂停只是它在等你签字。

提示5 · 用 Revert 做一次「无损试错」演练

在 Agent 改完代码后，先不点对勾，点 Revert 回退，然后换一种说法重新提同一个需求，对比两次生成的代码差异。这个练习同时验证两件事：回退功能真的可靠；提示词的措辞真的会影响产出。理解「可回退」这一课，比贪吃蛇本身更值钱。
